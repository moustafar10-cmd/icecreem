# حسابات مصنع الآيس كريم

أداة تفاعلية بصفحة واحدة (HTML/CSS/JS) لإدارة:

- تكاليف تأسيس مصنع الآيس كريم ورأس المال المطلوب
- الشركاء ونسبهم، وتسجيل دفعاتهم مع إثبات كل دفعة (تاريخ، طريقة دفع، رقم مرجع)
- التكاليف الثابتة والمتغيرة الشهرية، ونقطة التعادل والربحية المتوقعة
- سجل كامل لكل دفعات الشركاء، قابل للطباعة كإثبات

## طريقة الاستخدام

افتح ملف `index.html` مباشرة في أي متصفح، لا حاجة لأي تثبيت أو خادم. البيانات تُحفظ تلقائيًا في متصفحك (localStorage)، ويمكنك أخذ نسخة احتياطية JSON من داخل الأداة نفسها.

> ملاحظة: زرار "نسخة احتياطية" داخل الأداة مصمم للعمل عند فتحها كرابط Claude Artifact. عند تشغيلها كملف `index.html` عادي (من جهازك أو GitHub Pages)، استخدم أدوات حفظ الصفحة العادية في المتصفح، أو خذ نسخة من الملف نفسه بشكل دوري.

## النشر على GitHub Pages

1. اذهب إلى **Settings → Pages** في صفحة المستودع.
2. تأكد إن المستودع **Public** (Pages المجاني مش شغّال على مستودعات Private).
3. اختر Branch: `main` والمجلد `/root`، ثم احفظ.
4. خلال دقيقة هيظهر رابط مباشر مثل: `https://<username>.github.io/<repo-name>/`
