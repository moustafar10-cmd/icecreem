# حاسبة تأسيس المصنع

أداة تفاعلية بصفحة واحدة (HTML/CSS/JS بدون أي تبعيات خارجية باستثناء خطوط جوجل) لحساب:

- إجمالي رأس المال المطلوب لتأسيس المصنع
- التكاليف الثابتة الشهرية والتكاليف المتغيرة لكل وحدة
- نقطة التعادل (بالوحدات وبالإيراد)
- صافي الربح الشهري والسنوي المتوقع
- فترة استرداد رأس المال والعائد السنوي على الاستثمار (ROI)

## طريقة الاستخدام

افتح ملف `index.html` مباشرة في أي متصفح، لا حاجة لأي تثبيت أو خادم.

## النشر على GitHub Pages

بعد رفع المشروع إلى GitHub:

1. اذهب إلى **Settings → Pages** في صفحة المستودع.
2. اختر Branch: `main` والمجلد `/root`.
3. احفظ، وستحصل خلال دقيقة على رابط مباشر للأداة مثل:
   `https://<username>.github.io/<repo-name>/`

## ملاحظة

هذه الأداة تقديرية لمساعدتك على التخطيط المالي الأولي، ولا تُغني عن دراسة جدوى حقيقية أو استشارة محاسب/مستشار مالي متخصص.
